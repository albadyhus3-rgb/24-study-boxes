# 📚 24 Study Boxes

تطبيق ويب بسيط وفعال لتتبع الدراسة اليومية باستخدام نظام المربعات الـ24.

## 🎯 الفكرة الأساسية

تقسيم اليوم الدراسي إلى 24 مربع، حيث يمثل كل مربع ساعة واحدة من اليوم.

- **24 مربع = يوم كامل**
- **كل مربع = 1 ساعة**
- **كل مربع مكتمل = 4.17 درجة**
- **24 مربع مكتمل = 100/100 درجة**

## ✨ المميزات

### 1. 🎨 نظام المربعات
- 24 مربع منظمة في شبكة (6×4)
- تمثيل واضح لكل ساعة من اليوم
- حالات متعددة للمربع:
  - ⬜ لم أدرس
  - 🟩 تمت الدراسة (يحسب في النتيجة)
  - 🟦 تمت المراجعة
  - 🟪 تم حل MCQ
  - 🟨 دراسة جزئية

### 2. 📊 حساب النتيجة
- حساب تلقائي من 100 درجة
- عرض النتيجة الفورية
- شريط تقدم بصري
- نسبة الإنجاز اليومية

### 3. 🏆 إحصائيات شاملة
- إجمالي المربعات المكتملة
- مجموع ساعات الدراسة
- أفضل يوم
- متوسط الإنجاز اليومي
- السلسلة المتتالية (Streak)
- سجل كامل للأيام السابقة

### 4. 📝 تفاصيل كل مربع
عند الضغط على مربع، يمكنك:
- تحديد حالة المربع
- اختيار نوع النشاط (قراءة، مراجعة، MCQ، حفظ، محاضرة)
- كتابة اسم المادة أو المهمة
- إضافة ملاحظات

### 5. 💾 حفظ البيانات المحلي
- استخدام localStorage للحفظ المحلي
- **لا توجد حسابات أو تسجيل دخول**
- **لا توجد اتصالات خارجية**
- البيانات محفوظة للأبد على جهازك
- السجل الكامل للأيام السابقة

### 6. 🌙 الوضع الليلي
- تبديل سريع بين الوضع الفاتح والليلي
- يتم حفظ اختيارك

### 7. 📱 تصميم متجاوب
- Mobile First
- RTL (كامل الدعم للعربية)
- تصميم بسيط وحديث
- مناسب جداً للهاتف الذكي

## 🚀 كيفية الاستخدام

### التشغيل
1. افتح ملف `index.html` في المتصفح
2. أو استضفه على أي خادم ويب
3. أو استخدم GitHub Pages

### خطوات الاستخدام
1. **انظر إلى المربعات**: كل مربع يمثل ساعة واحدة من اليوم
2. **اضغط على مربع**: لفتح نافذة التفاصيل
3. **اختر الحالة**: حدد ما إذا كنت قد درست هذه الساعة
4. **أضف التفاصيل**: اكتب المادة والملاحظات (اختياري)
5. **احفظ**: اضغط حفظ لتحديث البيانات
6. **تابع التقدم**: لاحظ النسبة والنتيجة تتحدث تلقائياً
